Chrome'dan Diva Show sitesini yenile. Yeni API anahtarı veya env değişkeni gerekmiyor.

NASIL ÇALIŞIR?
* Mevcut Groq API çağrısı artık hem reply (cevap) hem mood (mimik) üretir; ikinci API çağrısı yok.
* normal = normal konuşma; angry = sinirli; surprised = şaşkın; wink = göz kırpma; celebrate = kutlama.
* Yapay zekâ kapalıysa, hata olursa veya kota dolarsa eski hazır cevap + mimik seçimi kullanılmaya devam eder.
* Akıllı otosohbette de cevabın duygusuna göre mimik seçilir.
* Karşılama, TikTok LIVE, Euler Stream anahtarı, seslendirme, öpücük animasyonu, 6 yüz görseli değişmedi.
* Default model openai/gpt-oss-20b için Groq Structured Outputs kullanılır. Model değiştirildiyse JSON modu kullanılır.
